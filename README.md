# Real Estate Price Analysis (Екатеринбург)

> **TL;DR:** спарсил ~1800 объявлений с Циан → геокодинг и расчёт расстояний → CatBoost (MAE ~13% от медианы) → SHAP для объяснения драйверов цены.
 
Модель на CatBoost для прогнозирования цены за квадратный метр жилья в Екатеринбурге и определения наиболее значимых факторов ценообразования. В ноутбуке `real_estate_analytics.ipynb` представлен ход анализа; файл `data.csv` хранит основную информацию об объектах, `data_with_cords.csv` — данные с географическими координатами.
 
## Описание проекта
 
Проведён анализ рынка жилой недвижимости Екатеринбурга и построена модель CatBoost для прогнозирования стоимости квадратного метра на основе характеристик квартиры и локации.
 
## Цель
 
Выявить ключевые факторы, влияющие на цену за м², и построить интерпретируемую модель для оценки стоимости объектов.
 
## Данные
 
Проанализировано ~1800 объявлений о продаже квартир (Циан, сбор через cianparser):
 
* характеристики квартиры (площадь, комнаты, этаж, тип дома);
* год постройки;
* расстояния до центра, метро и аэропорта;
* географические координаты объектов.
## Используемый стек
 
* Python
* pandas, NumPy — обработка и анализ данных
* CatBoost — модель прогнозирования цены
* SHAP — интерпретация модели, оценка вклада признаков
* scikit-learn — разбиение выборки, метрики качества
* geopy — геокодирование адресов и расчёт расстояний
* Plotly, Folium — визуализация и карты
* cianparser — сбор данных
* Jupyter Notebook — исследовательский анализ (EDA)
## Выполненные шаги
 
* Сбор данных с Циан и очистка: обработка пропусков, выбросов, приведение типов.
* Feature engineering: геокодирование адресов, расчёт расстояний до центра, метро и аэропорта; подготовка признаков для моделирования.
* Исследовательский анализ рынка недвижимости (EDA).
* Обучение модели CatBoost для прогноза цены за м².
* Интерпретация модели через SHAP для выявления драйверов стоимости.
## Метрики модели
 
* MAE ≈ 19 200 ₽/м² (~13% от медианной цены ~148 000 ₽/м²)
* RMSE ≈ 28 700 ₽/м²
## Ключевые результаты анализа
 
* Новостройки существенно дороже старого фонда.
* Расстояние до центра — один из сильнейших факторов снижения цены.
* Удалённость от метро влияет слабее, чем ожидалось.
* Большая площадь снижает цену за м² (эффект масштаба).
* Квартиры с большим числом комнат дешевле за м², чем студии и 1-комнатные.
* Высокие этажи и современные ЖК чаще связаны с более высокой стоимостью.
* Расстояние до аэропорта практически не влияет на цену.
## Итог
 
Модель CatBoost позволила количественно объяснить факторы ценообразования и может использоваться как базовый инструмент оценки стоимости недвижимости и анализа рынка.
